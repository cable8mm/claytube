# ClayTube 발표 대본

안녕하세요.
저희는 **ClayTube**를 만들고 있습니다.

ClayTube는 한마디로,

> **YouTube를 CMS처럼 사용해서, 나만의 브랜드 영상 포털을 만들어주는 오픈소스 CLI 도구입니다.**

많은 교육기관, 기업, 크리에이터들이 이미 YouTube를 콘텐츠 배포 채널로 사용하고 있습니다.

그런데 YouTube에 영상이 쌓이는 것과,
그 콘텐츠를 자신의 브랜드와 디자인을 가진 별도의 콘텐츠 사이트로 운영하는 것은 다른 문제입니다.

ClayTube는 바로 이 문제를 해결합니다.

사용자는 YouTube 채널 URL과 사이트 설정만 지정하면 됩니다.

그리고

```text
claytube sync
claytube build
claytube deploy
```

를 실행하면,

YouTube에서 영상을 가져오고,
정적 웹사이트를 만들고,
GitHub Pages에 배포할 수 있습니다.

핵심은 **서버도 없고, 데이터베이스도 없다는 것**입니다.

YouTube가 콘텐츠 CMS 역할을 하고,
ClayTube는 그 콘텐츠를 가져와 브랜드화된 정적 사이트로 만들어줍니다.

저희는 이 구조를 제품의 중요한 원칙으로 보고 있습니다.

**CLI-first, Static-first, Config-driven, Zero maintenance.**

그래서 사용자가 소스 코드를 직접 수정하지 않아도 사이트를 만들 수 있고,
운영 구조도 최대한 단순하게 유지할 수 있습니다.

디자인 역시 일반적인 대시보드가 아니라
TED.com처럼 콘텐츠 중심의 편집형 사이트를 지향합니다.

큰 썸네일, 깔끔한 타이포그래피, 최소한의 UI를 통해
영상 자체가 중심이 되는 사이트를 만드는 것입니다.

사용 사례도 명확합니다.

교육 콘텐츠 포털, 학원 영상 사이트, 기업 미디어 허브,
팬 커뮤니티, 그리고 정부기관이나 공공기관의 큐레이션 사이트 등에 사용할 수 있습니다.

비즈니스 모델은 조금 다르게 가져갑니다.

ClayTube 자체는 **무료 오픈소스**로 제공합니다.

무료 제품을 통해 사용자를 확보하고,
실제 사이트 사례와 신뢰를 쌓습니다.

그리고 수익은 소프트웨어 판매가 아니라
**구축, 디자인 커스터마이징, 관리형 호스팅, 기관 프로젝트**에서 만듭니다.

즉,

```text
오픈소스 제품
      ↓
실제 사이트 증가
      ↓
신뢰와 사례 축적
      ↓
구축 / 커스터마이징 / 호스팅 / 컨설팅
```

이라는 구조입니다.

저희가 만들고 싶은 것은 또 하나의 YouTube가 아닙니다.

YouTube에는 이미 콘텐츠가 있습니다.

ClayTube는 그 콘텐츠를 **자신의 브랜드를 가진 독립적인 콘텐츠 사이트로 만드는 가장 단순한 방법**을 제공하려고 합니다.

**YouTube를 CMS로, ClayTube를 publishing system으로.**

이것이 ClayTube의 핵심 아이디어입니다.
